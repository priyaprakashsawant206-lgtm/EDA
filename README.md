# Exploratory Data Analysis (EDA)

This repository contains my EDA practice using Python. It covers data cleaning, handling missing values, data transformation, encoding, statistical analysis, and data visualization.

### Tools & Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

### Topics Covered
- Data Cleaning
- Handling Missing Values
- Data Transformation
- Encoding Techniques
- Statistical Analysis
- Data Visualization

**Goal:** Learning and improving data analysis skills through hands-on practice with datasets.
